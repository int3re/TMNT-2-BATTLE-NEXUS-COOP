# Установка, обновление и удаление

[← К описанию мода](../README.md)

## Что нужно

- Windows 10 или 11.
- Установленная игра *TMNT 2: Battle Nexus* для ПК с файлом `TMNT2.exe` американского издания 2004 года.
  Этот же файл стоит в русских изданиях игры. Его SHA-256:

  ```
  22f49908bcd3b84278bea888b7285e1e0ba73a72a89764f495aceb76a42d8b6a
  ```

  С любым другим `TMNT2.exe` мод ничего не меняет: игра запустится как без него. Лаунчер предупредит об
  этом заранее.
- Для игры через Steam — запущенный клиент Steam. Сама игра в Steam не продаётся и покупать ничего не нужно.

## Установка

Мод ставит **[лаунчер](LAUNCHER.md)** — это единственный файл, который нужно скачать: мод лежит внутри него.

1. Скачайте `tmnt2net-launcher.exe` со страницы [Releases](../../../releases/latest) и запустите.
2. Лаунчер находит игру сам: в своей папке, по записи её установщика в Windows или в папках рядом с собой.
   Если не нашёл — укажите папку с `TMNT2.exe`.
3. Нажмите **УСТАНОВИТЬ МОД**, а потом **ИГРАТЬ**. Под главным меню игры появится строка с версией мода.

> Лаунчер не подписан сертификатом, поэтому Windows может показать «Система Windows защитила ваш
> компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».

Рядом с `TMNT2.exe` появятся:

| Файл | Что это |
|---|---|
| `winmm.dll` | Ultimate ASI Loader — загружает мод в игру. Если он уже стоит для другого мода, используется он |
| `tmnt2net.asi` | сам мод |
| `tmnt2net.ini` | настройки. При обновлении ваши значения сохраняются |
| `steam_api.dll`, `steam_appid.txt` | Steam для сетевой игры |
| `tmnt2net-README.md` | краткое описание и список изменений |
| `tmnt2net-install.txt` | список всего, что поставил лаунчер |

Файлы с такими же именами, которые лежали в папке раньше, лаунчер откладывает в `tmnt2net-backup\`.
`TMNT2.exe`, данные игры и ваше сохранение `tmntsave.dat` он не трогает.

Во время игры мод создаёт ещё несколько файлов:

| Файл | Что это |
|---|---|
| `tmnt2net.log` | журнал последнего запуска |
| `tmnt2net-sim.log` | журнал кадров сетевой игры, нужен для разбора рассинхронизаций |
| `tmnt2net-coop.rec`, `tmntsave-net.dat` | общий прогресс сетевой игры, см. [сетевую игру](NETPLAY.md#сохранения-и-прогресс) |

### Установка вручную

Скопируйте файлы из таблицы выше в папку игры. Взять их можно из папки `build/dist/Release` после
[сборки](BUILDING.md).

### Установка из командной строки

```bash
tmnt2net-launcher.exe /install "C:\Games\TMNT 2 - Battle Nexus" /quiet
```

`/quiet` убирает окно с отчётом: он пишется в консоль. Код возврата `0` — получилось, `2` — нет.

## Обновление

В лаунчере — кнопка **ОБНОВИТЬ**: он сам скачивает новую версию с GitHub, сверяет её и ставит. Если GitHub с
вашего ПК не открывается, скачайте новый `tmnt2net-launcher.exe` в браузере: новая версия мода внутри него.
Настройки в `tmnt2net.ini` сохраняются.

Для сетевой игры обновить мод нужно **всем игрокам**: версии должны быть совместимы, см.
[таблицу совместимости](CHANGELOG.md#совместимость-версий-в-сети).

## Удаление

В лаунчере: значок с ползунками вверху справа → **Удалить мод** (он спросит ещё раз). Из командной строки:

```bash
tmnt2net-launcher.exe /uninstall "C:\Games\TMNT 2 - Battle Nexus" /quiet
```

Что происходит:

- удаляются ровно те файлы, что были поставлены (по списку из `tmnt2net-install.txt`);
- отложенные файлы возвращаются из `tmnt2net-backup\`;
- журналы и сетевая копия сохранения `tmntsave-net.dat` стираются;
- ваше сохранение `tmntsave.dat`, `TMNT2.exe` и данные игры остаются как были;
- в `TMNT2.ini` остаётся разрешение, с которым игра запустится и без мода.

## Проверка, что мод работает

- под главным меню видна строка `tmnt2net 0.17.3`;
- в главном меню есть пункты **СЕТЕВАЯ ИГРА** и **НАСТРОЙКИ МОДА**;
- в папке игры появился `tmnt2net.log`, в его начале — строка `TMNT2.exe sha256 … (NA retail 2004, supported)`.

Если чего-то из этого нет — см. [«Если что-то не так»](TROUBLESHOOTING.md#мод-не-загружается).
